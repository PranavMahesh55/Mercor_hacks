# Mercor demo runbook

1. In Takecheck, open Demo kit and copy the generation prompt.
2. In HeyGen free, create a portrait presenter video. Keep it under one minute. Use the exact flawed script from the kit and readable captions if available. Do not publish the test clip as a factual ad.
3. Start the timer when submitting the render; stop when download becomes available. Record queue + processing time, plan, clip duration, and output resolution. This is one measurement, not a benchmark.
4. Download the video. Export at 720p if necessary to stay under 14 MB.
5. Upload the video to Takecheck. Load the approved Mercor brief, not the flawed prompt. Inspect and approve requirements before running review.
6. Connect Gemini using the session-only Settings field. Run review.
7. Inspect the source frame/audio at each finding, then Confirm or Dismiss it.
8. Export a correction brief. Open Transcript to demonstrate time-linked speech.
9. For a stable presentation, reopen the locally saved review. It is explicitly labeled Replay, with original analysis runtime. Do not reload the browser if you intend to run live and avoid reconnecting the key.
10. Run a correct control or segment to check false alarms. Report actual successes and misses.

Expected test candidates, subject to inspecting the actual HeyGen result:

- Written MERCURY instead of Mercor.
- 9 a.m. instead of 11 a.m.
- Guaranteed-job claim.

A different pronunciation is not evidence of written spelling. If no visual error is present, demonstrate a correct visual check rather than inventing one.

HeyGen says a one-minute Avatar Studio video usually takes about ten minutes, sometimes faster; queues may add substantial delay. Source: https://help.heygen.com/en/articles/9655503-heygen-video-processing-times
